## 🧪 Как самому зайти и потыкать Метрику (+ тест)

1. **metrika.yandex.ru** → войти под логином, к которому привязан счётчик `110042390`.
2. Открой счётчик → слева пункт **«Цели»**.
3. **Тестовая цель** (чтобы понять механику): «Добавить цель» → Название «Тест» → Тип условия **«JavaScript-событие»** → Идентификатор `test_goal` → «Добавить цель».
4. Убедись, что цель появилась в списке. (Сработать `test_goal` не будет — его нет в коде сайта, это нормально, цель тестовая.)
5. Потом тестовую цель можно удалить: три точки у цели → «Удалить».
6. Механику понял → дальше заводятся **реальные 5 целей** (`lead`, `phone_click`, `messenger_click`, `social_click`, `cta_click`) — по Word-инструкции. Их заведёт заказчик, либо ты сам (идентификаторы те же).

**Проверка реальных целей:** после создания открой yuristpro1.ru → нажми телефон, мессенджер, отправь пробную заявку → через 2–3 мин **Отчёты → Конверсии** покажут достижения.

## 📸 Какие 5 скринов сделать для Word

Пройди шаги в Метрике и сделай скрин каждого экрана. Порядок совпадает с местами в Word-файле:

1. **Список счётчиков** (или открытый счётчик № 110042390).
2. **Раздел «Цели»** с кнопкой «Добавить цель».
3. **Окно добавления цели** — чтобы было видно тип «JavaScript-событие» и поле «Идентификатор».
4. **Список целей** после создания.
5. **Отчёты → Конверсии**.

**Как вставить в Word:** открой `.docx` → кликни по пунктирному блоку «📷 Место для скриншота» → удали текст-заглушку → вставь картинку (перетащи файл или меню «Вставка → Рисунки»). Потом отправляй заказчику.

**Скрин на Mac:** `Cmd + Shift + 4` (выделить область) или `Cmd + Shift + 5`. Файлы падают на рабочий стол.
